## 一句话定位

> **杀戮尖塔式分支地图上，每次战斗都是一场"建造发展 → 择机进攻/防守"的 RTS 对局。**

---

## 游戏定位

本游戏是一款：
- Roguelike地图推进
- 自动化RTS战斗
- 局势驱动（优势 / 平势 / 劣势）
- 多阵营战场
- 玩家以"指挥官视角"进行微操干预

核心体验：
> "自动战斗 + 战略决策 + 局势变化"

---

## 核心循环

```
进入地图节点
→ 触发局势（优势/平势/劣势）
→ 自动战斗展开
→ 玩家可微操干预
→ 获得奖励（兵种/科技/强化）
→ 推进下一节点
```

### 战斗阶段详细循环

```
大地图阶段（杀戮尖塔式分支路径）
  ├─ ⚔️ 战斗（标注地形：优势/劣势/平势）
  ├─ ❓ 事件
  ├─ 🎁 奖励
  ├─ 🏕️ 休息
  └─ ⚠️ Boss
       │
       │ 选择战斗节点
       ▼
战斗阶段（地形决定开局条件）
  ├─ 🟢 优势 → 你已经建造好了（已有基地+兵力）
  ├─ 🔴 劣势 → 你需要时间建造（敌人已建好）
  └─ 🟡 平势 → 多方一起建造
       │
       ▼
  建造 ←→ 交战（同时发生）
  你决定什么时候进攻/防守
       │
       ▼
  胜负判定 → 结算奖励
```

---

## 局势系统

| 地形 | 你的开局 | 敌人的开局 |
|------|---------|-----------|
| 🟢 优势 | 已经建造好了，有基地和初始兵力 | 需要从头建造 |
| 🔴 劣势 | 需要从头建造 | 已经建造好了，有基地和兵力 |
| 🟡 平势 | 开始建造 | 多方同时开始建造 |

---

## 战斗系统

### 核心机制
战斗的核心就是一句话：
> **给你时间建造，但敌人可能在这期间来打你；你也可以趁敌人在建造时去打他。**

- 建造和交战不分阶段，**同时发生**
- 你可以选择 Rush（造几个兵就冲）
- 也可以选择防守（先造防御，稳住再打）
- 也可以均衡发展
- **敌人 AI 也在做同样的决策**

### 自动行为
- 单位自动寻路
- 自动攻击最近敌人
- 建筑自动生产单位

### 玩家干预
- 选中单位
- 微操移动
- 集火目标
- 临时撤退

### 胜利条件
- 摧毁敌方核心建筑
- 或 存活时间达成
- 或 特殊任务完成

## 单位系统

包含：
- 近战单位
- 远程单位
- 攻城单位
- 支援单位（未来扩展）

---

## 建筑系统

- 自动生产单位
- 自动提供资源
- 不支持复杂手动建造（第一版本）

---

## 地图系统

采用：
- 固定地图模板
- 随机出生点
- 随机资源点
- 局势决定初始状态

---

## 世界观（设计方向）

- **时代背景**：奇幻中世纪 — 魔法真实存在
- **势力格局**：不同阵营/兵种在分支地图上解锁
- **玩家身份**：一位指挥官，带领部队穿越危险地域
- **叙事方式**：事件节点分支选择 + 碎片化剧情解锁
