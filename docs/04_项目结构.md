# 项目结构 v1.0

> 本文件合并自：`STRUCTURE.md`（目标规范）、`项目结构与分析.md`「目录结构总览」节（现状扫描）

---

## 目标目录结构

```
units/          ← 单位逻辑
combat/         ← 战斗逻辑
ai/             ← AI逻辑
buildings/      ← 建筑逻辑
systems/        ← 系统逻辑
ui/             ← UI逻辑
map/            ← 地图逻辑
```

---

## 规则

- 单位逻辑必须在 `units/`
- 战斗逻辑必须在 `combat/`
- AI逻辑必须在 `ai/`
- UI必须独立 `ui/`
- 禁止跨目录写逻辑

---

## 命名规范

- PascalCase：节点
- snake_case：脚本变量
- signal统一用 `signal_` 前缀

## 渐进迁移策略

> 现有中文目录代码保持不动。
> **新代码**按目标结构放入对应英文目录。
> 重构旧代码到新目录不是当前任务。

| 旧目录 | 新目录 | 迁移状态 |
|--------|--------|---------|
| `单位/建筑/` | `buildings/` | 🟡 未来迁移 |
| `单位/剑士/` `单位/弓箭手/` | `units/` | 🟡 未来迁移 |
| `代码/攻击/` | `combat/` | 🟡 未来迁移 |
| `代码/组件代码/` | `systems/` | 🟡 未来迁移 |
| `UI/` `UI组件/` | `ui/` | 🟡 未来迁移 |
| `场景/` | `map/` 或 `scenes/` | 🟡 未来迁移 |
| `代码/` | 按类别拆分到各目录 | 🟡 未来迁移 |
