## UI 设计体系决策（2026-06-23）

### 架构决策
- 全屏 HUD 使用 CanvasLayer
- 营地覆盖层使用独立的 CanvasLayer（暗色背景 + 返回按钮）
- 容器嵌套替代手动定位
- Size Flags（Fill + Expand）实现弹性布局
- 锚点（Anchor）做全局定位
- NinePatchRect 做面板背景
- TextureButton 做互动按钮

### 视觉风格决策
- 字体：Uranus_Pixel_11Px.ttf（像素风中世纪）
- 按钮纹理：Blue_9Slides / Hover_9Slides（小剑资产）
- 面板纹理：Carved_9Slides（石雕风格，营地专用）
- 顶栏高度：44px
- 按钮字号：16
- 营地进入动效：0.6s 暗色淡入 + 相机平移
- 右侧按钮宽度：80px

### Theme 管理策略
- 用 Theme 资源统一全局控件样式，而非在每个节点上手写 overrides
- StyleBoxTexture + 九宫格（9-Slice）纹理实现可伸缩面板
- 字体、颜色、间距统一在一个主题文件中管理
