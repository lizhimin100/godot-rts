# Roguelike RTS (Godot 4.7)

杀戮尖塔式分支地图 × 轻量化建造-RTS × Roguelite 单机游戏。

## 项目信息

- **引擎**：Godot 4.7（GL Compatibility）
- **分辨率**：1280×720 视口
- **游戏类型**：Roguelike 地图推进 + 自动化 RTS 战斗
